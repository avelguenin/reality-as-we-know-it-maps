# Reality as we know it — argument & concept maps

Interactive argument map and concept map of the PhD dissertation
*Reality as we know it: Active Inference, contextuality and the common ground of socio-material practices*
by Avel Guénin–Carlut.

## Contents

- `index.html` — landing page
- `argument-map.html` — 115 arguments, typed support/opposition relations; chapter-column and force-directed network views
- `concept-map.html` — 179 concepts in three granularity tiers, clustered by thematic domain

All pages are fully self-contained static HTML (no external dependencies, no build step).

## Deploying on GitHub Pages

1. Push this folder to a repository (either as the repository root or as `/docs`).
2. In the repository settings, under **Pages**, choose **Deploy from a branch** and select the branch
   (and `/docs` if you used that folder).
3. The maps will be served at `https://<user>.github.io/<repo>/`.
